### Agentic tools の概念整理
- tool = エージェントが呼び出す function（例：read_file, search_web, execute_code）
- Claude Code で普段使っている操作（ファイル検索・コマンド実行など）がそのまま tool に相当すると理解
- broad な tool（何でもできる bash 1つ）の問題：error isolation 不可、least privilege 違反、explainability 低下

## 弱点・要復習

### 1. Domain 4 の核心（優先度：高）
- **何が弱いか**: Structured data extraction を「フォーマットの話」で止めた。`validation → retry with feedback` サイクルが抜けた
- **復習方法**: 3ステップ（schema → validate → retry）を手書きし、各ステップで「なければ何が起きるか」を書き足す

### 2. Domain 1 / Domain 5 の境界（優先度：高）
- **何が弱いか**: Conversational AI を「Domain 1 ではない」と判断。handoff も Domain 1 のトリガーという認識が薄かった
- **復習方法**: Domain 1 のトリガー条件（複数エージェント・handoff・human escalation）を3つ列挙し、8シナリオを再分類

### 3. Agentic tools の概念（優先度：中）
- **何が弱いか**: セッション冒頭で tool = アプリと誤解。英語文脈で再び混乱する可能性あり
- **復習方法**: 今日の Claude Code 操作を `tool名(引数) → 返り値` の形で3つ書く
