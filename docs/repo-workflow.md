# Repo Workflow

## 目的
このリポジトリは「計画」「日次実行」「記録」を分離して扱う。

## ファイルの役割
- `docs/study-plan.md`: 全体戦略
- `schedule/YYYY-MM-DD.md`: 当日の実行ページ
- `content/YYYY-MM-DD.md`: 必要に応じて作る詳細教材
- `tracker/progress.md`: フェーズ進捗
- `tracker/question-log.md`: 誤答・設計論点
- `tracker/vocabulary.md`: 英語メモ
- `tracker/mock-exams.md`: 模試ログ

## 日次フロー
1. `schedule/YYYY-MM-DD.md` を開く
2. `Preparation` を確認
3. `Today's Tasks` を実施
4. 必要なら `content/YYYY-MM-DD.md` を参照
5. `Study Log` を記録
6. `Carry Forward` に翌日への宿題を残す

## 3日分コンテンツ追加時の方針
- 1日1ファイルで `content/YYYY-MM-DD.md`
- 各ファイルに含めるもの:
  - その日の狙い
  - 前提知識
  - 学習本文
  - ミニ演習
  - 振り返りポイント
- まずは最初の3日分だけ作る
