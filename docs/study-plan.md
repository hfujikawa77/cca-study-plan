# CCA Study Plan

## Goal
2026-05-25 の Claude Certified Architect — Foundations 合格を狙う。

## Constraints
- まずは計画と記録基盤を作る
- 学習コンテンツ本文はまだ全部作らない
- 日毎にやることが見えること
- 後から最初の3日分のコンテンツを追加しやすい構造にする

## Exam Focus
- Agent architecture and orchestration: 27%
- Tool design and MCP integration: 18%
- Claude Code configuration and workflows: 20%
- Prompt engineering and structured output: 20%
- Context management and reliability: 15%
- 英語読解と用語慣れが重要

## Study Strategy
### Phase 1: 4/25-5/1 Foundation and map the terrain
- 試験全体像の把握
- 5ドメインを一周
- 苦手領域を見つける
- 英単語リスト開始

### Phase 2: 5/2-5/8 High-weight domains
- Agent architecture
- Claude Code workflows
- Prompt engineering / structured output
- 設計原則で判断する練習

### Phase 3: 5/9-5/15 MCP and reliability
- MCP tool design
- エラーハンドリング
- Context management
- Human escalation の判断軸

### Phase 4: 5/16-5/22 Mock exam loop
- 公式模試反復
- 誤答分析
- 時間配分の調整
- 英語読解の詰め

### Phase 5: 5/23-5/24 Final review
- 間違いノート確認
- 単語確認
- アンチパターン確認
- 試験環境チェック

### Phase 6: 5/25 Exam day
- 軽い見直しのみ
- 本番受験

## Daily Operating Rules
- 平日: 60-90分
- 休日: 2-3時間
- 毎回残すもの:
  - 学習時間
  - 完了タスク
  - わからなかった用語
  - 間違えた論点
  - 次回の1手

## Definition of Done per Day
- 当日タスクが見える
- 実績を記録できる
- 次の日に引き継げる
