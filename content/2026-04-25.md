## What This Exam Is Testing
Claude Certified Architect — Foundations は、Claude を実務システムに組み込むときの設計判断を問う試験。
暗記よりも、以下のような判断ができるかが中心になる。

- いつ 1 agent で十分か、いつ sub-agent に分けるべきか
- tool の責務をどう切るべきか
- structured output をどこまで強制するべきか
- context をどう保つか、どう削るか
- retry / validation / escalation をどう使い分けるか
- Claude Code や MCP をどう運用に乗せるか

要するに、**AI エージェント文脈での設計原則の適用力** を見られる試験。

## Domain Weights
優先順位づけの基準として、まず配点を覚える。

1. Agent architecture and orchestration — 27%
2. Tool design and MCP integration — 18%

### Quick Interpretation
- Domain 1 が最重要
- Domain 3 と 4 も重い
- Domain 2 と 5 は少し軽いが、実務判断に直結するので軽視しない
- 4択試験なので、知識不足より「筋の悪い選択肢を消せるか」が効く

## Core Mental Model
問題で迷ったら、まず次の観点で考える。

### 1. 最小権限
- 必要な権限だけ持たせているか
- 不要なツールを agent に与えていないか

### 2. 単一責任
- 1つの tool / agent に責務を盛りすぎていないか
- coordinator と specialist の役割が混ざっていないか

### 3. やりすぎない
- 要件に対して過剰設計していないか
- 本番導入前なのに複雑化しすぎていないか

### 4. 信頼性
- エラー時の動きが明確か
- validation / retry / escalation の方針があるか

### 5. コンテキスト管理
- 必要情報を保持できているか
- 不要情報を持ち込みすぎていないか
