## Core Concept 1 — What Makes a Good Tool
### 良い tool の条件
1. **単一責任**
   - 1 つの tool は 1 つのことをする
   - 例: `get_user_info` は取得のみ、更新は別の tool

2. **明確な境界**
   - tool が何をして、何をしないかが明確
   - 呼び出し側が結果を予測できる

3. **最小権限**
   - タスクに必要な権限だけ持つ
   - 読み取り専用で済むなら書き込み権限は与えない

4. **冪等性の意識**
   - 副作用がある tool は明確に識別できること
   - read と write を混在させない

5. **エラーが明確に返る**
   - 失敗したことが呼び出し側に伝わる
   - エラーの種類（一時的 / 永続的）が分かる

### One-line mental model
良い tool = 責務が 1 つ、権限が最小、失敗が見える

## Core Concept 2 — MCP Integration Basics
### MCP とは
MCP（Model Context Protocol）は、Claude が外部ツールやサービスを呼び出すための標準的なインターフェース。

### MCP の利点
- Claude と tool 実装を分離できる
- tool の追加・変更が Claude 側に影響しない
- 同じ tool を複数の agent から呼べる
- 権限やスコープを明示的に管理できる

### MCP tool の構成要素
- **name**: tool の識別子
- **description**: Claude が何に使うかを理解するためのテキスト
- **input schema**: 期待する入力の型と構造
- **出力**: 構造化されたレスポンス

### MCP tool の設計時の判断
- description が不正確だと、Claude が誤った文脈で呼び出す
- schema が緩すぎると、入力バリデーションが機能しない
- tool が多すぎると、Claude の tool selection が難しくなる

## Core Concept 3 — Tool Error Handling
エラー対応は、試験でよく問われる設計判断。

### エラーの種類
| 種類 | 特徴 | 対応方針 |
|---|---|---|
| 一時的エラー | ネットワーク、タイムアウト | retry |
| 恒久的エラー | 権限なし、存在しないリソース | retry しない |
| 不明エラー | 予期しない失敗 | escalation or fallback |

### Retry の使い方
- retry は一時的エラーにのみ使う
- retry 回数に上限を設ける
- 無限 retry は設計のアンチパターン

### Fallback の使い方
- 別の tool や手段で代替できるならそちらへ
- fallback 先もないなら、人間に escalation

### Error surfacing の原則
- エラーを握りつぶさない
- coordinator は sub-agent や tool の失敗を把握できること
- 失敗の種類と文脈を上位に渡す

## Tool Design Anti-patterns
### Anti-pattern 1 — God tool
1 つの tool に取得・更新・削除・通知を全部入れる。

なぜ悪いか:
- 責務が多すぎる
- 呼び出し側が何が起きるか予測しにくい
- エラー時の切り分けが難しい

### Anti-pattern 2 — Implicit side effect
tool の名前や description から副作用が読み取れない。

なぜ悪いか:
- Claude が意図せず破壊的操作を行う
- 人間がレビューしにくい

### Anti-pattern 3 — Over-permission
読み取りしか不要なのに書き込み権限まで持つ。

なぜ悪いか:
- 最小権限の原則違反
- 誤操作時のリスクが高い

### Anti-pattern 4 — Silent failure
tool がエラーでも成功を返す、または何も返さない。

なぜ悪いか:
- 呼び出し元が失敗を検知できない
- 不正確な結果が連鎖する

### Anti-pattern 5 — Description mismatch
tool の description が実際の動作と合っていない。

なぜ悪いか:
- Claude が誤った状況で tool を選ぶ
- 予期しない動作につながる
